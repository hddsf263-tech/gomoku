# 五子棋 Gomoku

一个本地双人对弈的五子棋网页程序。代码全部内置在单个 HTML 文件中，无需安装依赖，直接在浏览器打开 `index.html` 即可开始游戏。

## 功能

- 15 × 15 标准棋盘，黑方先手，点击交叉点落子
- 自动判定五连胜负，平局自动识别
- 悔棋、重新开始、当前手数与坐标提示
- 棋盘皮肤：翡翠、原木、墨玉、红木，支持上传照片作为棋盘背景
- 棋子皮肤：经典、玉石、曜石、琥珀，支持上传照片作为黑棋/白棋背景
- 落子特效：扩散光环、星光粒子、关闭
- 获胜特效：金色脉冲、彩带爆裂、关闭
- 落子音效：木声、清脆、水滴、静音
- 获胜音效：和弦、欢快、科幻、静音
- 支持导入本地音频文件作为自定义落子/获胜音效
- 全局音效开关
- 皮肤、特效与音效设置通过本地存储保留

## 使用

直接双击打开 `index.html` 即可游玩。

如果需要部署到 GitHub Pages，把本目录内容推送到仓库后，在仓库设置中启用 Pages 并将发布分支设为 `main`，访问地址通常为：

```
https://<username>.github.io/gomoku/
```
