## 7. Known Limitations（已知弱点）

### 当前版本的局限性

1. **搜索深度有限**
   - 困难模式仅 4 层搜索
   - 对于复杂战术组合可能计算不足

2. **棋型识别较为基础**
   - 仅识别单一方向的棋型
   - 对"双三"、"双四"等复合棋型识别不完善
   - 未区分"禁手"概念（标准五子棋黑棋禁手）

3. **无局面缓存**
   - 相同局面可能被重复计算
   - 影响搜索效率

4. **无迭代深化**
   - 固定深度搜索
   - 无法动态调整思考时间

5. **无连续威胁搜索 (VCT/VCF)**
   - 对于连续冲四取胜的局面可能漏算
   - 对于连续做杀的局面识别有限

6. **无开局库**
   - 开局阶段依赖通用算法
   - 未学习专业定式

7. **终局精度有限**
   - 对于复杂残局的精确计算不足
   - 无专门的终局数据库

8. **评估函数较简单**
   - 纯静态评分
   - 未考虑棋子协调性、厚薄等高级概念

### 架构预留说明

当前代码已为未来混合 AI 预留接口：

```cpp
// IAIPlayer.h - 抽象接口
class IAIPlayer {
    virtual AIMove getBestMove(const Board& board, ChessPiece myColor) = 0;
    virtual void setDifficulty(AIDifficulty difficulty) = 0;
};

// LocalAIPlayer - 当前实现
class LocalAIPlayer : public IAIPlayer { ... }

// 未来可扩展
// class HybridAIPlayer : public IAIPlayer { ... }
// class LLMBasedAI : public IAIPlayer { ... }
```

**重要设计原则**：

> 未来如果接入大模型，**不要让大模型直接取代本地五子棋核心规则**。

推荐架构：

```
┌─────────────────┐
│  本地算法层     │ ← 负责合法性、精确计算
│  (Local Core)   │
└────────┬────────┘
         │
┌────────▼────────┐
│  候选筛选器     │ ← 快速排除明显劣招
│  (Candidate     │
│   Filter)       │
└────────┬────────┘
         │
┌────────▼────────┐
│  大模型分析层   │ ← 形势判断、策略建议
│  (LLM Analysis) │   (可选，异步)
└────────┬────────┘
         │
┌────────▼────────┐
│  决策融合层     │ ← 综合本地计算和 AI 建议
│  (Decision      │
│   Fusion)       │
└─────────────────┘
```

## 10. 总结

### 当前 AI 能做什么

- ✅ 进行合法的落子
- ✅ 主动形成自己的连续棋型（活三、冲四、活四）
- ✅ 发现并阻止明显的对手威胁（冲四必防）
- ✅ 识别基本棋型并给出合理评分
- ✅ 不在无关位置随机落子
- ✅ 进行 2-4 层的未来局面搜索
- ✅ 在明显存在胜着时优先选择胜着
- ✅ 在对手即将获胜时优先防守（依赖深度）
- ✅ 正确处理游戏结束

### 当前 AI 不能做什么

- ❌ 计算非常深远的战术组合 (>4 层)
- ❌ 完美处理复杂的"双三"、"双四"局面
- ❌ 像职业棋手一样进行大局观判断
- ❌ 在极短时间内完成高质量搜索
- ❌ 从历史对局中学习
