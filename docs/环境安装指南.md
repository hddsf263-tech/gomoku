# Qt 开发环境安装指南

本指南将帮助您在 Windows 系统上安装 C++ Qt 开发环境，以便编译和运行五子棋项目。

## 方案一：Qt 官方安装包（推荐）

### 步骤 1：下载 Qt Online Installer

1. 访问 Qt 官方网站：https://www.qt.io/download-qt-installer
2. 点击 "Download Qt Online Installer" 按钮
3. 注册一个免费的 Qt 账户（必需）
4. 下载安装程序 `qt-online-installer-windows-x64-*.exe`

### 步骤 2：运行安装程序

1. 双击下载的安装程序
2. 点击 "Next"，登录您的 Qt 账户
3. 选择安装路径，建议使用默认：`C:\Qt`
4. 选择组件时，**务必勾选以下项目**：

   ✅ **Qt 6.5.0** (或最新的 LTS 版本)
     - ✅ MinGW 11.2.0 64-bit compiler
     - （可选）MSVC 2019 64-bit compiler（如果已安装 Visual Studio）
   
   ✅ **Qt Creator 10.0.0** (或最新版本)
     - ✅ CDB Debugger Tools
     - ✅ Debugging Tools for Windows
   
   ✅ **Developer and Designer Tools**
     - ✅ Qt Charts
     - ✅ Qt Data Visualization
     - ✅ Qt PDF

5. 确认安装摘要，点击 "Install"
6. 等待安装完成（可能需要 15-30 分钟，取决于网络速度）
7. 点击 "Finish" 完成安装

### 步骤 3：验证安装

1. 打开 Qt Creator：
   - 在开始菜单搜索 "Qt Creator"
   - 或访问 `C:\Qt\Tools\QtCreator\bin\qtcreator.exe`

2. 检查编译器：
   - 打开 Qt Creator
   - 点击 "工具 (Tools)" → "选项 (Options)"
   - 选择 "Kits" 标签
   - 确认看到 "Desktop Qt 6.5.0 MinGW 64-bit"

3. 检查命令行工具：
   ```bash
   # 打开 PowerShell，运行：
   C:\Qt\6.5.0\mingw_64\bin\qmake.exe --version
   C:\Qt\Tools\mingw1120_64\bin\g++.exe --version
   ```

## 方案二：使用 vcpkg 安装（高级用户）

如果您已经安装了 Visual Studio，可以使用 vcpkg 包管理器：

```powershell
# 1. 克隆 vcpkg
git clone https://github.com/Microsoft/vcpkg.git
cd vcpkg
.\bootstrap-vcpkg.bat

# 2. 安装 Qt6
.\vcpkg install qt6-base:x64-windows

# 3. 集成到 Visual Studio
.\vcpkg integrate install
```

然后在 Visual Studio 中创建 CMake 项目，CMake 会自动找到 Qt。

## 方案三：使用 MSYS2 安装

```powershell
# 1. 下载并安装 MSYS2
# 访问 https://www.msys2.org/

# 2. 打开 MSYS2 UCRT64 终端，运行：
pacman -S mingw-w64-ucrt-x86_64-qt6
pacman -S mingw-w64-ucrt-x86_64-cmake
pacman -S mingw-w64-ucrt-x86_64-gcc

# 3. 添加到 PATH
# C:\msys64\ucrt64\bin
```

## 编译五子棋项目

### 方法 A：使用 Qt Creator（推荐）

1. 打开 Qt Creator
2. 点击 "文件" → "打开文件或项目"
3. 选择 `gomoku/CMakeLists.txt`
4. 选择构建目录：`gomoku/build`
5. 选择 Kit："Desktop Qt 6.5.0 MinGW 64-bit"
6. 点击 "配置项目"
7. 点击 "构建" → "运行" 或按 `Ctrl+R`

### 方法 B：使用命令行

1. 打开 **Qt Creator 自带的终端**：
   - 在开始菜单搜索 "Qt 6.5.0 (MinGW 11.2.0 64-bit)"
   - 或运行 `C:\Qt\Tools\mingw1120_64\mingw64_shell.bat`

2. 导航到项目目录：
   ```bash
   cd C:\Users\Lenovo\Documents\ChatGPT\杂项事务\gomoku
   ```

3. 创建构建目录并配置：
   ```bash
   mkdir build
   cd build
   cmake -G "MinGW Makefiles" ..
   ```

4. 编译：
   ```bash
   cmake --build .
   ```

5. 运行：
   ```bash
   .\Gomoku.exe
   ```

### 方法 C：使用 CMake GUI

1. 下载并安装 CMake：https://cmake.org/download/
2. 打开 CMake GUI
3. "Where is the source code": 选择 `gomoku` 文件夹
4. "Where to build": 选择 `gomoku/build`
5. 点击 "Configure"
6. 选择生成器："MinGW Makefiles"
7. 如果有错误，设置 `CMAKE_PREFIX_PATH` 为 `C:/Qt/6.5.0/mingw_64`
8. 点击 "Generate"
9. 点击 "Open Project" 或手动编译

## 常见问题解决

### 问题 1：CMake 找不到 Qt

**错误信息**: 
```
Could not find a package configuration file provided by "Qt6"
```

**解决方案**:
```bash
cmake -DCMAKE_PREFIX_PATH="C:/Qt/6.5.0/mingw_64" ..
```

或在 CMakeLists.txt 中添加：
```cmake
list(APPEND CMAKE_PREFIX_PATH "C:/Qt/6.5.0/mingw_64")
```

### 问题 2：缺少 DLL 文件

**错误信息**:
```
无法启动程序，因为计算机中丢失 Qt6Core.dll
```

**解决方案**:

方式 1 - 使用 windeployqt 工具：
```bash
cd build
copy C:\Qt\6.5.0\mingw_64\bin\Gomoku.exe .
C:\Qt\6.5.0\mingw_64\bin\windeployqt.exe Gomoku.exe
```

方式 2 - 将 Qt bin 目录添加到 PATH：
```powershell
$env:Path += ";C:\Qt\6.5.0\mingw_64\bin;C:\Qt\Tools\mingw1120_64\bin"
```

### 问题 3：编译时出现中文乱码

**解决方案**:
在 CMakeLists.txt 中添加：
```cmake
add_compile_options(/utf-8)
```

或在代码文件开头添加：
```cpp
#pragma execution_character_set("utf-8")
```

### 问题 4：链接错误 LNK2019

**错误信息**:
```
unresolved external symbol __imp_...
```

**解决方案**:
确保 CMakeLists.txt 中正确链接了 Qt 库：
```cmake
target_link_libraries(${PROJECT_NAME} PRIVATE Qt6::Core Qt6::Gui Qt6::Widgets)
```

## 验证安装成功

编译完成后，您应该能够：

1. ✅ 看到 `Gomoku.exe` 可执行文件
2. ✅ 双击运行程序
3. ✅ 看到主窗口（包含棋盘和控制面板）
4. ✅ 点击"新游戏"开始对局
5. ✅ 鼠标点击棋盘落子
6. ✅ 黑白双方轮流下棋
7. ✅ 形成五连时弹出胜利提示
